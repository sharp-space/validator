# SVL011: Cross-property target is compiled at runtime

| | |
| --- | --- |
| Severity | Warning |
| Category | Sharp.Validator |

## Message

> Cross-property target '{0}' is not a member chain, so it is compiled when the validator is built: NativeAOT runs it interpreted, and trimming can remove an operator it needs; compare against a property, or check the value with Must((value, context) => ...)

## Cause

SVL011 is reported only when `EnableTrimAnalyzer` is `true`, as `PublishTrimmed`, `PublishAot`, `IsTrimmable`, and
`IsAotCompatible` make it.

`GreaterThan`, `GreaterThanOrEqual`, `LessThan`, `LessThanOrEqual`, `Equal`, and `NotEqual` take their target as an
expression, and the expression forms of `InclusiveBetween` and `ExclusiveBetween` take both bounds that way. A target
that is a member chain rooted at the lambda parameter, such as `x => x.Policy.Min`, reads through an accessor the
source generator precompiles. Any other target is an expression tree compiled for each validator instance: a computed
value such as `x => x.Minimum * 2`, a constant, a method call, or a static member.

- Native AOT runs the compiled expression in the expression interpreter, measured at about four times the time and
  some 200 more bytes per validation.
- An expression applying an operator the runtime looks up by reflection, such as `*` on `decimal`, can't be built
  once trimming has removed the operator, so building the validator throws.

## How to fix

Compare against a property, or check the computed value with a delegate, which is never an expression tree.

```csharp
// Flagged: the target is computed, not a member chain.
Builder.Property(x => x.Quantity).GreaterThan(x => x.Minimum * 2);

// Fixed
Builder.Property(x => x.Quantity).Must((quantity, context) => quantity > context.Model.Minimum * 2);
```

To keep a comparison rule's error code and default message, add the rule with a delegate target:

```csharp
Builder.Property(x => x.Total).Add(new EqualValidator<Order, decimal>(x => x.Price * x.Quantity));
Builder.Property(x => x.Quantity).Add(new GreaterThanValidator<Order, int>(x => (true, x.Minimum * 2), targetPropertyName: null));
```

## Suppression

SVL011 is a warning. Suppress it only when the consequence above is what you want.

```csharp
#pragma warning disable SVL011
// ...
#pragma warning restore SVL011
```

```ini
# .editorconfig
dotnet_diagnostic.SVL011.severity = none
```
